# CloudSync Backup Service

## Overview
CloudSync is a backup tool that automatically saves your files to the cloud
every hour. It supports Windows, Mac, and Linux computers.

## Pricing
- Free plan: 5GB storage, backs up once per day
- Plus plan: $8/month, 200GB storage, backs up every hour
- Business plan: $25/month, 2TB storage, backs up every 15 minutes

## Features
CloudSync includes automatic file versioning, meaning you can restore
any file to how it looked up to 30 days ago. It also has ransomware
detection, which pauses backups if it notices unusual file changes.

## Support
Support is available by email for all plans. Business plan customers
also get access to live chat support, available Monday to Friday,
9am to 6pm.
